# ServerTextCN_Mcode —— 魔兽世界 3.3.5 服务器文本汉化插件

**把服务器实时发来的英文文本，翻译成中文显示。**

在你辛辛苦苦装好中文客户端之后，是不是还遇到过这种情况：

- 跟 NPC 对话，窗口顶部一大段**英文问候语**；
- 训练师、商人、传送门的**选项按钮全是英文**；
- 进了战场，屏幕上刷的**开场倒计时、旗帜攻防播报全是英文**；
- 登录后系统公告也是英文。

这不是你装漏了汉化包——**汉化包只能翻译客户端文件里本来就有的文字**（任务描述、物品名、界面文字）。而 NPC 问候、菜单选项、战场播报这些内容，是**服务器在你点击的那一刻实时下发的**，客户端文件里根本没有它们，任何"烤进客户端"的汉化都覆盖不到。

本插件就是在游戏运行时，把这些"服务器现发英文"拦下来，用**内置词典**替换成中文再显示。纯客户端行为，不需要任何服务端配合。

---

## 功能一览

| 功能 | 覆盖内容 | 说明 |
|---|---|---|
| **窗口汉化** | NPC 对话问候、训练师问候、任务问候、对话菜单选项按钮 | 四层匹配（精确 → 大小写/占位符还原 → NPC 骨架 → NPC 相似度），未收录的原样显示 |
| **播报与公告汉化** | 战场开局倒计时、旗帜拾取/夺取/归还、据点攻防，以及系统公告 | 24 条战场规则 + 系统公告词典 |
| **漏译收集** | 遇到没收录的英文，自动记录原文 + NPC、地点、时间等现场信息 | 屏幕提示条 + 聊天框提醒，可一键复制成反馈；3.2 起反馈附带"占位符与变量线索"分析（判断 `$n`/`%s` 等动态变量，供 AI 补译参考） |
| **记录查看** | 已翻译/未翻译记录可搜索、翻页、查看详情、复制 | 全部只读，游戏内不可误改 |

词典规模（随 3.1 发布）：问候语 **5,396** 条、菜单选项 **1,995** 条，另附 **3,413 + 1,764** 个 NPC 名称的收敛索引（用于相似度匹配）。所有翻译都在本地完成，**不联网、不上传任何数据**。

## 适用环境

- **客户端**：魔兽世界 3.3.5a（build 12340），Windows / macOS 均可；客户端本身是英文、繁中、简中界面都可以用。
- **服务器**：任何 3.3.5 服务端。作者在英文服务器上开发测试；服务器措辞与词典键有差异时，未命中的文本会保留英文并进入漏译记录。
- **依赖**：无。独立运行，不依赖 ElvUI 等任何其他插件。
- **注意**：如果你在用旧版的战场播报插件 **Mcode_BGTextCN**，两者不要同时启用——本插件已完整合并它的 24 条规则，检测到旧版会自动暂停公告模块并提示处理。

## 快速开始（3 步）

1. **下载**：在本项目页面点击绿色 `Code` 按钮 → `Download ZIP`，解压得到 `ServerTextCN_Mcode` 文件夹。
2. **放入插件目录**：把整个 `ServerTextCN_Mcode` 文件夹复制到
   `游戏目录\Interface\AddOns\` 下（没有这两个文件夹就新建；`游戏目录` 就是 Wow.exe 所在的文件夹）。
3. **进游戏验证**：登录后输入 `/stcn show`，能弹出设置页即安装成功。

> 每一步的详细截图位置、易错点和排查方法见 **[《安装指南》](docs/01-安装指南.md)**。

## 命令速查

| 命令 | 作用 |
|---|---|
| `/stcn` 或 `/stcn show` | 打开设置页（记住上次停留的功能页） |
| `/stcn on` / `/stcn off` | 一键开/关窗口汉化 + 公告汉化 |
| `/stcn debug` | 开关窗口匹配调试日志（排查问题时用） |
| `/stcn dump` | 在聊天框输出记录统计和最近的漏译清单 |

也可以通过 **ESC → 界面 → 插件 → ServerTextCN_Mcode** 打开图形设置页。日常使用详见 **[《使用指南》](docs/02-使用指南.md)**。

## 参与贡献

欢迎以下三种参与方式（门槛从低到高）：

1. **报告漏译 / 误译**：进游戏复现 → 设置页选中记录 → 点击"复制反馈" → 到项目仓库提一个 Issue 粘贴即可。带现场信息的反馈修复最快。
2. **自己补词条**：按 [03-补译与贡献指南](docs/03-补译与贡献指南.md) 的 AI 提示词流程回填本地词典自用，顺手把词典文件和反馈一起提交 Pull Request。
3. **改代码 / 补公告规则**：请先阅读 [04-工作原理](docs/04-工作原理.md)，公告规则集中在 `AnnouncementRules.lua`，格式和边界都有注释。

提交词条请务必遵守**词典版本号规则**（格式 `年.月.日.修订号`，内容变化必须递增）——这是所有汉化分发包判断"词典有没有更新"的唯一依据，指南里有详细说明和自动维护工具。
