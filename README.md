# ServerTextCN_Mcode · 服务器文本汉化

![WoW 3.3.5a](https://img.shields.io/badge/WoW-3.3.5a-blue) ![离线词典](https://img.shields.io/badge/翻译-内置词典-informational)

把服务器实时下发的 NPC 问候、对话菜单、训练师文字，以及战场、系统和首领公告翻译成中文。适用于魔兽世界 3.3.5a，独立运行，游戏内不联网、不上传记录，也不连接 AI 服务。

[下载源码 ZIP](https://github.com/MuyuQ/ServerTextCN-Mcode/archive/refs/heads/main.zip) · [使用与补译指南](docs/USAGE.md) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/MuyuQ/ServerTextCN-Mcode/issues)

## 功能

| 功能 | 范围 |
|---|---|
| 窗口汉化 | NPC 问候、菜单、训练师等；自动应用精确匹配、变量还原和同一 NPC 的安全格式变体 |
| 播报与公告汉化 | 已收录的战场、系统与首领公告规则，保留玩家名、数字和链接等动态字段 |
| 漏译与误译反馈 | 收集原文及现场信息，支持查看、搜索、复制和清空记录 |
| 离线扩充词典 | 提供记录后由维护者审核补译，更新插件内的词典文件 |

当前窗口词典包含 **5,423 条问候语、2,022 条菜单选项**，另有 **53 条公告规则**。未收录或不能确定匹配的文字保留原文，不把近似句子直接替换成已知译文。

## 安装

1. 完全退出游戏，备份已有插件目录和账号存档。
2. 下载并解压仓库 ZIP，取出解压目录内的 **`ServerTextCN_Mcode`** 文件夹（其中包含 `ServerTextCN_Mcode.toc`）。
3. 将整个插件文件夹放入 `Interface/AddOns/`，确认 TOC 直接在该目录下。
4. 重新启动游戏并启用插件，输入 **`/stcn show`** 打开设置。

公共仓库 ZIP 的插件位于解压目录内的 `ServerTextCN_Mcode/`；从独立维护源下载时，以 TOC 所在目录为准，不要把项目外层目录整体套入 AddOns。

如仍有旧 `Mcode_ServerTextCN` 或 `Mcode_BGTextCN`，退出游戏后移出其旧目录。新版已经合并相关功能；检测到旧战场插件时会暂停公告模块并提示处理，窗口汉化仍可用。其他版本客户端、任意服务器措辞和所有公告的完整覆盖均不作保证。

## 使用

设置入口为 `/stcn show` 或 **ESC → 界面 → 插件 → 服务器文本汉化**。窗口汉化和播报与公告各有独立开关，漏译收集可单独设置。

| 命令 | 作用 |
|---|---|
| `/stcn` / `/stcn show` | 打开上次功能页 |
| `/stcn on` / `/stcn off` | 同时开启／关闭两个汉化功能，保留收集设置 |
| `/stcn debug` | 切换窗口匹配调试 |
| `/stcn dump` | 查看版本和记录报告 |

已安装插件或词典更新后通常可 `/reload`，再重访同一 NPC 或触发公告核对；首次安装新 TOC 要完全重启。修改 MPQ 的重启要求另行遵循对应汉化包说明。

## 内置词典与反馈

窗口词典位于 `ServerTextCN_Mcode_Data.lua`，公告规则位于 `AnnouncementRules.lua`，均随插件提供。游戏内不编辑翻译规则；窗口词典和公告词典各自维护版本号。

反馈时提供原文、期望译文、NPC 或公告来源、插件及词典版本，必要时附截图。在“未汉化记录”或“汉化记录”中复制反馈，可保留变量和现场线索。分享存档前检查并移除不希望公开的角色、地点或消息内容。

维护者和 AI 的完整补译步骤、变量处理与验证要求见 [使用与补译指南](docs/USAGE.md)。只修改说明或界面时不递增词典版本；修改译文后应更新对应词典版本并复验。
