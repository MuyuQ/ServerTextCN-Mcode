# 05 · 常见问题（FAQ）

## 安装与加载

**Q：装好了，但进游戏一点效果都没有？**

按顺序排查：

1. 角色选择界面左下角"插件"列表里有没有 `ServerTextCN_Mcode`？没有 → 目录层级错了（`.toc` 必须在 `AddOns\ServerTextCN_Mcode\` 这一层），见 [01-安装指南](01-安装指南.md) 第四步。
2. 插件前面的勾有没有打上？勾了之后要点"重新加载UI"或重进游戏。
3. `/stcn show` 能打开设置页吗？能 → 开关状态正常，继续第 4 步。
4. 你看到的英文是哪来的？本插件只翻**NPC 问候/菜单、训练师问候、任务问候、战场播报、系统公告**。任务描述、物品名、技能提示、玩家聊天**不在覆盖范围**——那些属于客户端文本（装汉化包解决）或刻意不接入。
5. 具体某句英文没翻 = 词典未收录，属正常现象，见 [03-补译与贡献指南](03-补译与贡献指南.md)。

**Q：新装/更新插件后一定要重启游戏吗？**

新装或删除了文件、改了 `.toc`：完全重启客户端最稳。只替换了已存在的 `.lua`（比如更新词典）：进游戏 `/reload` 即可。

**Q：/reload 是什么？**

游戏内置命令"重新加载界面"：把所有插件停止再重新加载，不用重启整个游戏。聊天框输入 `/reload` 回车即可。

**Q：和整合包/汉化包冲突吗？**

不冲突。本插件是独立外置插件，只做显示层替换，不改客户端文件。唯一注意点：如果整合包里还带着旧版 `Mcode_BGTextCN`（战场播报插件），本插件公告模块会自动暂停并提示，按 [02-使用指南](02-使用指南.md) "旧插件冲突"一节停用旧版即可。

**Q：和 ElvUI、DBM 这类插件冲突吗？**

不冲突。本插件不依赖也不修改它们。DBM 的首领报警走自己的音视频通道，与本插件的首领公告翻译互不干扰。

## 功能与效果

**Q：为什么有的翻有的不翻？**

词典决定一切：收录了就翻，没收录就原样显示并（开着收集时）自动记录。收录工作靠实发反馈逐条推进，"宁可漏翻、不可错翻"。

**Q：翻译带的角色名/职业是对的，但有些占位符显示成了 `$n` 或 `$g兄弟:姐妹;` 本身？**

译文占位符取不到角色信息时按设计保留原样（宁可显示 `$n` 也不显示空串）。通常发生在登录最早期；重新触发一次对话即可。

**Q：能翻译玩家聊天/任务正文吗？**

不能。玩家聊天是真人发言；任务正文属于客户端本地文本，由汉化包负责。本插件的边界见 [04-工作原理](04-工作原理.md) 的"已知边界"。

**Q：训练师问候翻不了？**

训练师问候语不在任何公开语料库里，靠服务器实发逐条收编。确认插件版本较新后仍未翻，走漏译反馈流程。

**Q：漏译提示条点了没反应？**

战斗中点击只会提示"战斗结束后输入 /stcn show 查看"，这是受保护状态下的刻意设计。提示条消失不影响记录。

**Q：记录会无限增多吗？**

不会。未汉化记录 ≤300 条、汉化记录 ≤200 条（每模块），满了淘汰最久未出现的。重要的尽早"复制反馈"。

**Q：误译了怎么办？**

设置页切"查看汉化记录" → 选中那条 → "复制反馈" → 提 Issue。词典更新后，重新触发那句话就会按新译文显示。

**Q：怎么彻底重置插件（当全新安装）？**

完全退出游戏 → 删除 `WTF\Account\<账号>\SavedVariables\ServerTextCN_Mcode.lua` → 进游戏。所有开关回到默认、记录清空。插件本体不用动。

## 数据与安全

**Q：这个插件会联网/上传我的数据吗？**

不会。翻译查的是本地词典文件，记录保存在本机 `WTF` 存档里，没有任何网络请求。

**Q：安全吗？会不会封号？**

本插件只做客户端显示层替换，不发网络包、不改服务器交互、不读存档之外的数据、游戏内不可执行自定义规则（3.1 起已移除一切编辑功能）。这是 3.3.5 插件里风险最低的一类。但请知悉：任何第三方插件都不在官方支持范围内，是否使用、在哪台服务器使用，请自行判断并遵守该服务器的用户协议。

**Q：存档里的记录能给别的账号/朋友用吗？**

可以。`SavedVariables\ServerTextCN_Mcode.lua` 是纯文本，复制到对方同路径即可（游戏关闭时操作）。它只包含设置与记录，不含词典本体。

## 界面与字体

**Q：中文显示成 "？" 或方块？**

这是**客户端字体问题**，与本插件无关：客户端缺少中文字体时所有中文都会变问号。安装中文字体或中文客户端字体补丁（`Fonts` 文件夹 / 字体 MPQ）即可，汉化整合包一般已带。

**Q：设置页里文字挤在一起/看不全？**

设置页支持拉伸窗口自适应；记录页在"收集设置"展开状态空间不足时会提示收起后查看详情。界面缩放（系统设置里的 UI 缩放）也会影响布局。

## 其他

**Q：客户端是英文界面能用吗？**

能用。插件不依赖客户端语言；服务器下发英文、客户端是英文/繁中/简中都一样处理。

**Q：多开/多客户端怎么办？**

每个客户端目录是独立的：插件要装进你实际登录的那个客户端的 `Interface\AddOns`；`WTF` 存档也按客户端目录区分。

**Q：更新后怎么确认词典真的更新了？**

`/stcn show` 父页面（或 `/stcn dump`）看"窗口词典 / 公告词典"版本号是否变化，格式 `年.月.日.修订号`。详见 [02-使用指南](02-使用指南.md) 的"版本号怎么看"。

**Q：我是服务器管理员，想让服务器直接发中文？**

本插件帮不了那个方向——那是服务端本地化（给服务端数据库导入 zhCN locale 表）的课题。本插件解决的是"动不了服务端"的场景。
