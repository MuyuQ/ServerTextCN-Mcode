# 01 · 安装指南（手把手版）

这份指南假设你**完全没有装过魔兽插件**。每一步都写清楚"在哪里、点什么、看到什么算成功"。装过插件的老玩家可以直接跳到[第四步](#第四步把插件文件夹放进-addsons)。

> 本插件适用于**魔兽世界：巫妖王之怒 3.3.5a（build 12340）**客户端。不确定自己客户端版本的，看[这里](#开始前确认客户端版本)。

---

## 开始前：确认客户端版本

1. 启动游戏，进入登录界面（输入账号密码那个画面）。
2. 看界面**左下角**，有一行小字：`Version 3.3.5 (12340)` 或类似 `3.3.5a` 字样 —— 说明版本正确，继续往下。
3. 如果显示 1.12 / 2.4.3 / 4.x 等其他版本，本插件不适用（界面 API 不同，强行加载会报错）。

## 第一步：下载插件

**方式 A：从 GitHub 下载（推荐）**

1. 打开本项目仓库页面。
2. 点击绿色的 **`<> Code`** 按钮。
3. 在弹出的小菜单里点 **`Download ZIP`**，浏览器会下载一个压缩包。
4. 找到下载好的压缩包（一般在"下载"文件夹），**右键 → 全部解压**（或用 7-Zip / WinRAR 解压）。
5. 解压后会得到一个文件夹，里面有 `README.md`、`ServerTextCN_Mcode` 等。**我们要用的就是里面那个叫 `ServerTextCN_Mcode` 的文件夹**（判断标准：打开它能看到 `ServerTextCN_Mcode.toc` 这个文件）。

**方式 B：用 Git 克隆（适合会 Git 的人）**

```bash
git clone <仓库地址>
```

克隆完成后，进入仓库目录，同样取 `ServerTextCN_Mcode` 文件夹。

**方式 C：朋友直接拷给你**

让朋友把整个 `ServerTextCN_Mcode` 文件夹原封不动发给你（压缩打包再传，避免文件损坏）。收到后解压，核对里面有 `ServerTextCN_Mcode.toc` 即可。

## 第二步：找到"游戏目录"

**游戏目录 = 启动游戏用的 Wow.exe 所在的文件夹。**

如果你是双击桌面的快捷方式启动游戏：

1. 右键点击桌面上的游戏快捷方式。
2. 选 **属性**。
3. 点 **打开文件所在的位置**（Win10/11）或看"目标"一栏里的路径。
4. 打开的这个文件夹就是游戏目录——里面应该能看到 `Wow.exe`、`Data`、`WTF`（玩过才会有）等文件和文件夹。

> 如果你的电脑里有多个 3.3.5 客户端（比如一个原版一个整合包），**插件要装进你平时玩、并且装了汉化包的那个客户端**。装错了客户端等于没装。

## 第三步：找到（或新建）Interface\AddOns 文件夹

插件统一放在游戏目录下的 `Interface\AddOns\` 里。

1. 在游戏目录里找名为 **`Interface`** 的文件夹。
   - 找到了 → 双击进入。
   - 没找到 → 说明从没装过插件：在游戏目录空白处**右键 → 新建 → 文件夹**，命名为 `Interface`（大小写随意），进入后再新建一个文件夹命名 `AddOns`。
2. 进入 `AddOns` 文件夹。以后你装任何插件，都是把插件文件夹放进这里。

> 常见整合包/汉化包客户端已经有 `Interface\AddOns`，里面躺着 ElvUI、DBM 等一堆文件夹——这就对了，`ServerTextCN_Mcode` 以后和它们并排住在一起。

## 第四步：把插件文件夹放进 AddOns

把第一步得到的 **整个 `ServerTextCN_Mcode` 文件夹**（不是里面的单个文件，也不是外层的仓库文件夹）复制进 `AddOns`。

复制完成后，检查一下目录结构是不是这样：

```text
游戏目录\
└─ Interface\
   └─ AddOns\
      └─ ServerTextCN_Mcode\          ← 就是这一层
         ├─ ServerTextCN_Mcode.toc    ← 关键文件，必须在这一层
         ├─ Core.lua
         ├─ Window.lua
         ├─ ...（其余 .lua 文件）
         └─ README.md
```

**最容易犯的错：多套了一层。** 如果你复制成了下面这样，游戏找不到插件：

```text
AddOns\ServerTextCN-Mcode\ServerTextCN_Mcode\...   ← ✗ 外面多套了一层仓库文件夹
AddOns\ServerTextCN_Mcode\ServerTextCN_Mcode\...   ← ✗ 同样多套了一层
```

**判断标准只有一条**：`ServerTextCN_Mcode.toc` 必须位于 `AddOns\ServerTextCN_Mcode\` 这一层。

## 第五步：启动游戏，启用插件

1. 完全启动游戏（新装插件后，**最稳妥是重新启动一次客户端**；已经在游戏里的话，也可以先试 `/reload`）。
2. 停在**角色选择界面**（选人画面）。
3. 看屏幕**左下角**，有一个 **插件** 按钮，点击它。
4. 列表里应该出现 **`ServerTextCN_Mcode 服务器文本汉化`**，并且版本号与所下载版本一致（如 3.3）。
   - 列表里没有它 → 回到[第四步](#第四步把插件文件夹放进-addsons)检查目录层级；
   - 它前面的勾没打上 → **勾上它**，然后点右下角**重新加载UI**（或回到角色选择再进入游戏）。

## 第六步：进游戏验证

1. 进入游戏世界。
2. 按 **回车** 打开聊天框，输入：

   ```text
   /stcn show
   ```

3. 弹出"**ServerTextCN_Mcode 服务器文本汉化**"设置页 → ✅ 安装成功。
4. 想直观看效果：
   - 找任意一个 NPC 对话，已收录的问候语和菜单选项会直接变成中文；
   - 去训练师那里，"你好！准备好接受训练了吗？"这类问候语会显示中文；
   - 进一场战场，开局倒计时和据点播报会显示中文。

如果设置页能打开，但某些英文还是没翻——那是**词典还没收录这句**，不是安装问题。开着默认的"漏译收集"继续玩，插件会自动记录，然后按 [03-补译与贡献指南](03-补译与贡献指南.md) 处理。

## 更新插件版本

1. 下载新版，得到新的 `ServerTextCN_Mcode` 文件夹。
2. **完全退出游戏**。
3. 用新文件夹整体覆盖 `AddOns\ServerTextCN_Mcode`（先删旧的再放新的也可以）。
4. 启动游戏，输入 `/stcn show`，在父页面核对"插件版本 / 窗口词典 / 公告词典"三个版本号是否变成了新版数字。

> 只更新了词典文件的场合，进游戏执行 `/reload` 即可生效；更新了 `.toc`、新增/删除了文件时，请完整重启客户端。

**从旧名插件（Mcode_ServerTextCN）升级**：插件改名后，存档文件名也跟着变了。想保留之前的漏译/翻译记录：

1. 完全退出游戏；
2. 打开 `游戏目录\WTF\Account\<你的账号>\SavedVariables\`；
3. 把 `Mcode_ServerTextCN.lua` 重命名为 `ServerTextCN_Mcode.lua`；
4. 再进游戏。记录会自动迁移到存档结构 4。

## 卸载

1. 完全退出游戏。
2. 删除 `AddOns\ServerTextCN_Mcode` 整个文件夹。
3. （可选，彻底清空记录）删除 `WTF\Account\<账号>\SavedVariables\ServerTextCN_Mcode.lua`。

## 安装问题排查表

| 现象 | 原因与解决 |
|---|---|
| 角色选择界面插件列表里没有本插件 | 目录多套了一层（`.toc` 不在 `AddOns\ServerTextCN_Mcode\` 这一层）；或装进了另一个客户端；或文件夹名被改成了不含 `.toc` 的空壳 |
| 插件列表里有，但进游戏 `/stcn` 提示"存档尚未加载" | 刚进游戏太早，等几秒再试；仍然报错就重启客户端 |
| 加载时报红字 Lua 错误 | 文件在传输中损坏或缺文件，重新解压一份完整的；确认客户端是 3.3.5a |
| 设置页能开，但什么都没翻 | 见 [05-常见问题](05-常见问题.md) 的"装了没效果"逐项排查 |
| 与"界面→插件"里另一项 Mcode_BGTextCN 同时存在 | 本插件公告模块会自动暂停并提示；按 [02-使用指南](02-使用指南.md) 的"旧插件冲突"一节处理 |
| 修改过插件里的文件后全部失效 | 用系统自带记事本保存会破坏 UTF-8 编码；改文件请用 VS Code / Notepad++ 并以 UTF-8（无 BOM）保存 |
