# 02 · 使用指南

安装成功后，这个插件**基本不需要你做任何事**——已收录的文本会自动变成中文。这一页讲清楚它能配置什么、提示条怎么用、记录去哪看。

## 打开设置页

两种方式，效果相同：

- 聊天框输入 **`/stcn show`**（或只输 `/stcn`）；
- **ESC → 界面 → 插件 → ServerTextCN_Mcode**。

设置页结构：

```text
ServerTextCN_Mcode（父页面）
│   插件作用、汉化范围、使用方法、内置词典位置、更新汉化的说明
│   调试开关、"停用旧版并重载"按钮（有冲突时才出现）
│   版本信息：插件版本 / 窗口词典版本 / 公告词典版本
├── 窗口汉化（子页面）
└── 战场播报与屏幕公告（子页面）
```

`/stcn` 不带参数会打开**上次最后停留**的功能页。

## 两个功能模块

### 窗口汉化（子页面一）

覆盖四类窗口文本：**NPC 对话问候、训练师问候、任务问候、对话菜单选项按钮**。

页面顶部是"启用窗口汉化"总开关（默认开启）。关掉后所有窗口文本恢复英文原样，但已有记录仍可查看、搜索、复制。

下面的"未汉化记录 / 汉化记录"列表和收集设置，见本文后面[记录页](#记录页查翻译查漏译)一节。

### 战场播报与屏幕公告（子页面二）

覆盖**战场系统的播报**（开局倒计时、旗帜拾取/丢弃/夺取/归还、据点占领/进攻/防守/摧毁）和**系统公告**（登录欢迎语、角色交易说明、`/join global` 世界频道提示等）。

页面顶部是"启用播报与公告汉化"开关（默认开启）。

点击底部"**展开收集设置**"，可以看到四个**采集来源**开关：

| 采集来源 | 对应内容 | 默认 |
|---|---|---|
| 战场系统播报 | 战场开场、旗帜、据点类消息 | 开 |
| 系统通知 | 登录欢迎、系统公告 | 开 |
| 首领公告 | 团本首领喊话（含首领密语） | 开 |
| 屏幕信息提示 | UI_INFO_MESSAGE 类屏幕提示 | **关** |

> 注意：来源开关只控制"**没翻译的英文要不要记录下来**"，不影响已有内置翻译的显示。内置翻译始终生效。

## 漏译提醒：聊天框 + 屏幕提示条

只要你**开着"收集未汉化文本"**（窗口页与公告页各自的开关，默认开），插件遇到没收录的英文时：

1. 聊天框出现一条绿字提示：`已记录未汉化[窗口｜NPC名]：原文摘要…；/stcn show 查看`；
2. 屏幕上方弹出**金色提示条**，显示 3 秒：

```text
发现未汉化文本，已记录
窗口汉化 · 点击查看记录
```

- 连续遇到多条漏译，提示条合并计数（"已记录 3 条未汉化文本"），从最后一次刷新重新计时 3 秒。
- **点击提示条**直接跳到对应记录（自动切到"未汉化记录"页并选中那条）。
- 战斗中点击只会提示"战斗结束后输入 /stcn show 查看"，不会强行打开界面。
- 提示条没有声音、不抢焦点，消失了记录也还在。

同一次 NPC 对话里重复刷新的相同文本不会重复记录；关掉窗口下次再遇到，会更新"出现次数"并再次提醒。

## 记录页：查翻译、查漏译

两个子页面各有一套记录区，结构相同：

- **"查看汉化记录 / 查看未汉化记录"按钮**：在两个列表间切换。
- **搜索框**：按原文、译文、NPC 名、地点、类型、来源模糊搜索（不区分大小写）。
- **记录列表**：最近出现的排最前。每行显示 NPC（或来源）· 原文摘要，第二行是时间和出现次数；带"历史"标记的是旧版插件留下的记录，译文不代表当前词典。
- **点击任意一行**：下方文本框显示完整原文与现场信息（NPC 与 ID、地点坐标、来源、事件、时间、次数、采集时的词典版本、匹配方式等）。
- **复制反馈**：把选中记录连同现场信息整理成一段文字并自动全选，按 Ctrl+C 复制，即可粘贴到项目仓库的 Issue（见 [03-补译与贡献指南](03-补译与贡献指南.md)）。**插件不会自动发送任何数据。**
- **清空当前记录**：清空当前页签的全部记录（包括被搜索隐藏的），有确认弹窗；不影响另一个页签。

**容量与淘汰规则**：每个模块的未汉化记录最多 **300** 条、汉化记录最多 **200** 条。超出上限时，最久没有再次出现的记录会被淘汰。重要漏译请尽早复制反馈。

## 命令详解

| 命令 | 作用 | 备注 |
|---|---|---|
| `/stcn` / `/stcn show` | 打开设置页 | 打开上次停留的功能页 |
| `/stcn on` | 同时开启窗口汉化和公告汉化 | 两个开关本来就能在各自页面单独控制 |
| `/stcn off` | 同时关闭两个功能 | 关闭后已有记录保留 |
| `/stcn debug` | 开/关窗口匹配调试日志 | 与父页面的调试勾选项同步 |
| `/stcn dump` | 输出记录报告 | 两个模块各自的记录条数、最近的漏译清单、当前词典版本 |

**调试日志长这样**（排查"为什么这句没翻"时开）：

```text
[服务器文本汉化] 窗口命中[精确匹配｜菜单｜旅店老板] 原文：I'd like to browse your goods.
[服务器文本汉化] 译文：我想看看你的商品。
[服务器文本汉化] 窗口未命中[训练师｜铁匠阿米尔] 原文：Greetings, $N.
```

命中行会标明匹配方式：`精确匹配`（词典直接命中）、`NPC骨架匹配`（忽略大小写标点后的当前 NPC 词条命中）、`NPC相似度匹配 sim(0.93)`（与当前 NPC 候选词条相似度达标）。中文文本不会打印"未命中"。同一次对话里相同内容不重复打印；在窗口打开之后才开调试的，关掉对话重开一次即可。

## 版本号怎么看

父页面（以及 `/stcn dump`）显示三个版本：

| 版本 | 变化意味着 |
|---|---|
| 插件版本（如 3.1） | 插件代码更新了功能或修复 |
| 窗口词典版本（如 2026.09.30.1） | 问候/菜单词条有增改（换NPC和菜单内容去验证） |
| 公告词典版本（如 2026.10.01.1） | 战场规则或系统公告有增改（重新触发对应公告去验证） |

三个版本互相独立。词条更新不需要更新插件版本号，反之亦然。

## 旧插件冲突（Mcode_BGTextCN）

本插件已完整合并旧战场播报插件 Mcode_BGTextCN 1.3 的全部规则。如果旧插件还在运行（有些整合包把它烤在客户端 MPQ 里），本插件的公告模块会**自动暂停**并在父页面提示"旧战场插件正在运行，公告模块已暂停"，避免同一条播报被处理两次。

处理：父页面点击"**停用旧版并重载**"（会弹出确认，然后自动停用旧插件并重载界面）。如果按钮不可用，去角色选择界面的插件列表手动取消勾选 Mcode_BGTextCN。个别烤入 MPQ 的旧插件无法在游戏内停用时，按你整合包的说明处理，或咨询整合包作者。

## 记录存在哪、什么时候保存

所有设置和记录都保存在本机：

```text
游戏目录\WTF\Account\<你的账号>\SavedVariables\ServerTextCN_Mcode.lua
```

- 记录**按账号共享**：同一个账号下所有角色共用一份（现场信息里会记录是哪个角色采集的）。
- 正常执行 `/reload` 或正常退出游戏时会写入硬盘；游戏崩溃时当次新记录**不保证**保留。
- 复制这个文件（或直接把"采集记录"交给 AI）就是备份；插件本体在 `Interface\AddOns` 里，两者互不影响。
